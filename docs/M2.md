# M2 Driving

Done on 2026-11-08: the plan in #24, then stacked PRs #25–#28, with the Q1–Q17 defaults. M2 made the road drivable: a pure `CarSim` (auto-speed, junction braking, off-road damage, health), a pure `JunctionTrigger`, an `Autopilot`, the `GameState` and `EventBus` autoloads, and the game scene with input, pause, a HUD and a camera. The full plan, with its verification, negative cases and review history: `git show 08f316f:M2_PLAN.md`.

## 1. Goal and exit criteria

Goal (IP §3): "A human can drive with touch or keyboard; auto-speed, off-road, health and junction judging work; sim tests pass".

E1–E13 covered the rules, 300 autopilot turns on each of 20 seeds (E5), the game scene, the smoke run, the Web and Fold4 checks (E12) and green CI. All were met but E12's Fold4 part, which the plan doesn't record (§7).

## 2. Findings

- **H1.** IP braked at the constant `BRAKE` (4 tiles/s²) only 0.75 tiles before the junction tile, so the autopilot entered too fast and crashed on all 20 seeds. Fix: within `junction_brake_distance`, brake at max(`BRAKE`, (v² − t²) / (2 · (d − 0.5))), d being the distance to the junction's centre, to enter the tile at the target t. `AreaDef.validate()` requires a brake distance ≥ `least_brake_distance()`, 0.617 tiles at 60 Hz (Q1).
- **H2.** IP set `DRIVING` after `on_rejoin()`, reviving a run that a dead-end rejoin had ended. Fix: set it first.
- **H3.** Only UI overlays had `process_mode = ALWAYS`, so a key released while paused stayed held. Fix: the `InputRouter` and the HUD get it too; the rest pauses with the tree.
- **H4.** Losing focus sends no key-up or touch-up events, and `Input.release_pressed_events()` clears only `Input`'s state, only after `NOTIFICATION_APPLICATION_FOCUS_OUT`. The Web never sends that: a blur of the window or the canvas reaches nodes only as `NOTIFICATION_WM_WINDOW_FOCUS_OUT` (display_server_web.cpp:843–845, window.cpp:898–903). Fix: the `InputRouter` drops everything held on either notification, and `main.gd` pauses the run on either (Q4, N46).
- **H5.** `on_rejoin()` read `tile.junction`, which M1 removed (docs/M1.md G1). Fix: `tile.junction_index`.
- **H6.** `reload_current_scene()` takes the scene out of the tree before `retry_requested.emit()` returns. Fix: the HUD marks the input handled first.
- **H7.** Enter pressed a clicked II again. Fix: `focus_mode = NONE`.
- **H8.** The mouse couldn't steer. Fix: `pointing/emulate_touch_from_mouse` (Q6).
- **H9.** IP's `TouchZones` did only what II's `mouse_filter` (STOP) does. Fix: none (Q5).
- **H10.** A step through a cell corner has no heading. Fix: `CarSim` reports each cell entered, in order, and whether it's on the road there.
- **H11.** An edge without road could decide an exit. Fix: require `junction.has_exit(exit)`.
- **H12.** D6's "near" had no origin. Fix: the car's cell after the step that leaves the road.
- **H13.** A rejoin can pass two junctions. Fix: `on_rejoin()` resolves each in order.
- **H14.** IP's trigger needed the autoloads. Fix: a pure `RefCounted`; `main.gd` relays its signals.
- **H15.** D2's "300+ turns in well under a second" fails for 20 seeds (8.2–9.5 s). Kept (Q11).
- **H16.** A lambda that uses `self`, connected to a signal of an object that `self` holds, keeps `self` alive: `GDScriptLambdaSelfCallable` holds a `Ref<RefCounted>` to it (gdscript_lambda_callable.h:73). The cycle is never freed; GUT still passes, but `run_tests.sh` fails on its leak guard (docs/M1.md G1), as N2 shows. Fix: the sim objects connect methods, never lambdas.
- **H17.** Nothing checked that the autopilot keeps driving. Fix: with `--autopilot`, the end of a run is a `push_error`.
- **H18.** `expand` with integer scaling leaves black margins on the Fold4 (§6.5). Not fixed (Q17).
- **H19.** Sim tests without `main.gd` ran out of road. Fix: `CarSim` calls `buffer.on_car_path_index()` itself (N34).
- **H20.** No art or audio yet. Fix: a `Polygon2D` arrow (§5.7) and `CPUParticles2D` dust (Q12).
- **H21.** The frame came from the velocity, undefined at rest. Fix: from the heading.
- **H22.** IP's `start_run(seed := -1)` would shadow the built-in `seed()` (docs/M1.md G13), and `run_seed` the member. Fix: `start_run(p_run_seed)`; `main.gd` picks the seed (D8).
- **H23.** The editor warned that each `EventBus` signal was unused. Fix: `@warning_ignore_start("unused_signal")`.
- **H24.** A method `area()` would add 2 SHADOWED_VARIABLE warnings. Fix: `RoadGenerator.find_area(id)`.
- **H25.** `plan.md` §7.3 let a paused run end. Fix: §5.5's transitions.
- **H26.** IP's zoom `snap()` was undefined. Fix: the nearest step by ratio (§5.8).
- **H27.** The HUD's distance was unspecified. Fix: the farthest point reached (Q9).
- **H28.** IP had no retry. Fix: a tap or Enter retries at once. A forced `--seed` stays for every retry; without it, each run gets a new random seed (Q2).
- **H29.** M1's code has 8 editor warnings. Left (Q13).
- **H30.** IP's boot test had no input, so its run ended at the first junction. Fix: it drives with the autopilot.
- **H31.** `JunctionTrigger` seeks the next junction as the car leaves one, when the buffer surely holds only `BUFFER_REFILL_AT` tiles past it (25 then, 37 now); past the buffer, judging stops with a `push_error`. M2's gaps were at most 14 tiles. M4's `AreaSchedule.validate()` checks that `gap()`, set piece + longest straight + 1, is ≤ `BUFFER_REFILL_AT` (docs/M4.md K1).

### 4.5 Landing the stack

Each PR branched from the one before and targeted its branch, so its diff showed only its files. Only a PR based on `main` is merged: the required checks gate only those. A review fix goes on the branch of the PR that adds the file and is merged up; never rebase or force-push. After PR n's squash-merge, PR n+1 merges `origin/<PR n branch>` and `origin/main`, checks that `git diff --name-only origin/main` lists only its files, pushes and retargets to `main`. That push starts no Copilot review: `gh pr edit <n> --add-reviewer @copilot`.

## 5. Design

### 5.1 Files

§4 lists them. IP's `ui/touch_zones.tscn` and `ui/pause.tscn` were never added (Q3, Q5).

### 5.2 Driving values

`AreaDef` gained `straight_accel`, `junction_brake_distance`, `junction_speed`, `offroad_speed_mult`, `offroad_damage_per_sec` and `offroad_limit_tiles`, with the City's as defaults (Q10).

### 5.3 Junction trigger

`JunctionTrigger` keeps `turn_index` and `next_junction`. `on_cell_crossed()` decides an exit only on the road, out of the junction cell, through one of its exits (H11). `on_rejoin(tile)` (D5) resolves the junctions passed (H13); a dead end is a disaster. `on_offroad_limit()` is a missed turn, `choice` −1. It updates, then emits `disaster_triggered(junction, choice)` or `turn_completed`.

### 5.4 Car simulation

`CarSim` works in tile space (D1); its causes are `wrong_turn`, `missed_turn`, `health` and `offroad`. `step(delta, steer)` moves, then updates the path for each cell entered (H10, H19), so whatever ends a run sees the car where the step ends; then it applies the rules cell by cell via `RoadGeometry.on_road_spans()` (D4). The target speed is `junction_speed + straight_accel · dist_on_straight`, capped by `BASE_TOP_SPEED` growing to `GLOBAL_SPEED_CAP`; `junction_speed` within the brake distance; times `offroad_speed_mult` off the road. Off the road, health drains; at `offroad_limit_tiles` it's a missed turn near a junction (H12), else `offroad`. `Autopilot` steers by pure pursuit.

### 5.5 Game state and events

`GameState`'s transitions (H25): TITLE → RUNNING; RUNNING → PAUSED, DISASTER, CRASH or TITLE; PAUSED → RUNNING or TITLE; DISASTER and CRASH → GAME_OVER or TITLE; GAME_OVER → RUNNING or TITLE. Others are a `push_error`. `end_run(cause)` emits `run_ended(cause, stats())`. `EventBus` has `plan.md` §7.4's 8 signals plus `car_offroad_changed` and `paused_changed`.

### 5.6 Input

`InputRouter.steer()` is 0 while disabled, else the autopilot's (Q8) or the latest input held (Q7): keys by physical keycode, touches by index. Disabling it, or either focus notification (H4), drops everything held.

### 5.7 Car view

`CarController` (`car/car.tscn`) steps its `CarSim` in `_physics_process` and shows the nearest of 16 screen directions (H21). M2 drew a white `Polygon2D` arrow; M5's `%Body` `Sprite2D` replaced it (docs/M5.md §5.7).

**Draw each `Polygon2D` once.** In Godot 4.7.2, each redraw of a `Polygon2D` after its first raises WebGL errors on the Web, even with the same shape. Setting its `color` redraws it, and such a redraw binds a buffer in a way WebGL forbids: in E12's Web check, the browsers logged two WebGL `INVALID_OPERATION` warnings a frame (`bindBuffer`, then `bufferSubData`), until they stopped reporting them, after 256 in Chrome and 32 in Firefox. This is godotengine/godot#124726, fixed for 4.8 by godotengine/godot#124764. So #28 kept the arrow white and tinted it through `self_modulate`, not `color`: once drawn, a polygon changes only its transforms, `modulate` and `self_modulate`. docs/M4.md K9 and docs/M6.md S6 add that its `polygon`, `offset` and `visible` never change either. Tests fail on a `draw` after the first frames: `test_none_redraws_a_polygon` (`test_disasters.gd`) and the `*_is_never_redrawn` tests of the tunnel, the bridge and `Daylight`. The legends, set pieces, `ViewVeil`, `Lamps`, `Shadows` and `SkidMarks` cite this rule. It holds until Godot 4.8.

### 5.8 Camera

`CameraRig` moves `1 − exp(−CAMERA_SMOOTHING · delta)` of the way to `target()` each physics frame: the car plus `LOOKAHEAD_PX` ahead, raised in portrait by `PORTRAIT_BIAS`. `zoom_for(size)` picks the `CAMERA_ZOOMS` step nearest by ratio to min(size.x, size.y) / (`VISIBLE_TILES` · 71.55 px) (H26).

### 5.9 HUD

`Hud` (`process_mode = ALWAYS`) shows distance, turns, health, II, a message, and the version and seed. Its root, top bar and health bar have `mouse_filter = IGNORE`, so touches reach the `InputRouter`. M3 moved the end-of-run message and retry to a game-over screen (docs/M3.md J10).

### 5.10 Main scene

`main.gd` reads `--seed=N` (else a random seed, D8) and `--autopilot`, puts the car under `World/%Props`, and relays the sim's and trigger's signals to `GameState` and `EventBus`. With `--autopilot`, `_exit_tree()` prints `autopilot: tile %d, turns %d, area %s` for `smoke.sh`. M3 retries without reloading the scene (docs/M3.md J13).

### 5.11 CI scripts

Only `smoke.sh`'s comment changed.

### 5.12 Tuning

`config/tuning.gd` gained the speeds (`GLOBAL_SPEED_CAP` 7 tiles/s), steering, `START_HEALTH`, the camera's constants (`VISIBLE_TILES` 5, `CAMERA_ZOOMS` [0.5, 1, 2]) and `METRES_PER_TILE`, unchanged since.
