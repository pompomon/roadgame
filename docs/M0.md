# M0 Bootstrap & CI

Planned on 2026-11-06 and done on 2026-11-07: the plan and PR 1 in #2, then PRs 2–4 in #3, #6 and #10. These merged only into their stack branches, so #16 landed them on `main`, and #18 landed #17, the Actions storage change (F34). M0 made the empty Godot 4.7.2 project with GUT 9.7.1, and CI that lints, loads every script, runs the tests and a smoke run, exports the Web build, APK and AAB, deploys Pages and makes releases. Its scripts fail on the errors after which Godot and GUT still exit 0. The full plan, with M0's final files (appendices A and B), verification, negative cases and review history: `git show 08f316f:M0_PLAN.md`.

## 2. Findings

High: F1–F7, F29, F30. Medium: F8–F20, F31, F32. Low: the rest.

- **F1.** GUT exits 0 when a test script doesn't parse, such as on an untyped declaration (D12), and skips its tests. `run_tests.sh` fails on the parse error.
- **F2.** `godot --import` compiles no scripts, so one that no scene loads went unchecked. `check_scripts.sh` loads every script.
- **F3.** Without the import cache, `.godot/`, GUT runs 0 tests and exits 0. `run_tests.sh` fails on its "have not been imported" line and on 0 tests.
- **F4.** IP's determinism grep missed real calls, or all of them when a folder was missing, and flagged seeded calls, comments and strings. `lint.sh` lexes GDScript instead (§5.5).
- **F5.** A `-s` script with a runtime error before `quit()` hangs until the job's 6 h limit. `run_godot` adds a time limit, and every job sets `timeout-minutes`.
- **F6.** `project.godot` had no `config/version`, and IP's `stamp_version.sh` broke on `08`, bad input and parts over 999 (D9). It now has `config/version="0.0.0"`, and the script validates `[v]X.Y.Z`.
- **F7.** In a container job, `${{ runner.temp }}` is the host's path, so signed exports would fail. `release.yml` uses `$RUNNER_TEMP` (§5.8).
- **F8.** gdlint and gdformat fail on a missing path, and git can't commit IP M0.1's empty folders. `lint.sh` passes only folders that exist, and each folder comes with its first file.
- **F9.** IP's `.gutconfig.json` named test folders before they existed, and GUT only logged `[GUT ERROR]`. It names `res://tests/`, with subfolders.
- **F10.** Godot exits 0 after printing errors, and IP's `import.sh` missed engine `ERROR:` lines. The scripts scan Godot's log (§5.5).
- **F11.** Godot 4.7.2's Gradle build needs NDK 29.0.14206865, which the image lacks. `godot-env` installs it.
- **F12.** `export.sh` put its log in the Web build, which Pages published. Logs go to `build/reports/`.
- **F13.** Exports held GUT, the tests and the tools. Every preset excludes them (§5.4).
- **F14.** Redefining `ui_accept` drops its default events, and A/D bound by `keycode` move on AZERTY. §5.1 binds physical keys.
- **F15.** gdlint's `max-public-methods: 20` fails a GUT file with over 20 tests. `.gdlintrc` sets 40.
- **F16.** Agent sessions had no Godot or gdtoolkit. PR 1 added `copilot-setup-steps.yml` (§5.9).
- **F17.** Pages was off, and ruleset "Test" targeted `~ALL`, so its rules hit every branch. Owner actions, done.
- **F18.** Godot makes `*.uid` and `*.import` files that must be committed, and scripts need the executable bit: `git add --chmod=+x tools/ci/*.sh`.
- **F19.** IP's manual release input, `0.1.0`, made a tag outside `v*.*.*`. The input is the tag (`v0.1.0`), validated before any build.
- **F20.** Each Godot job pulls `barichello/godot-ci:4.7.2`, about 2.6 GB, under Docker Hub's anonymous limits. Kept, with §8's mitigations (Q6).
- **F21.** gdtoolkit 4.5.0 declares Python only up to 3.10. 3.12 is verified, and `tools/ci/requirements.txt` pins gdtoolkit for all.
- **F22.** Workflows and shell scripts weren't linted. `lint` runs actionlint, and `lint.sh` shellcheck.
- **F23.** The import cache key ignored the Godot version. Moot: no caches (F34).
- **F24.** IP's `check_versions.sh` could exit silently, and missed odd tags (`4.7.2-rc1`, `latest`) and the agent's setup. It compares complete tags (§5.10).
- **F25.** `build/` wasn't `.gdignore`d, so a later export packed exported files. `build/.gdignore` is committed.
- **F26.** Exports were checked only for a non-empty file. A Web export needs `.js`, `.wasm` and `.pck`, and an APK or AAB an `arm64-v8a` `.so`.
- **F27.** `release.yml` lacked `pipefail`, the script check and some timeouts. Fixed (§5.8).
- **F28.** The scripts assumed GNU tools, bash 4 and `godot` on `PATH`. They allow bash 3.2, BSD tools and a `GODOT` override; never run on macOS.
- **F29.** GUT ignores errors in the `before_*` and `after_*` hooks, and exits 0. `tests/gut_post_run.gd` exits 1 on them, unless the hook asserted them.
- **F30.** Headless Android exports fail without `import_etc2_astc`, which Godot implies only on ARM hosts. `project.godot` sets it.
- **F31.** In container jobs `$HOME` is `/github/home`, but Java takes `user.home` from `/etc/passwd`, so Gradle's home is `/root/.gradle`, which the Gradle cache step missed. F34 dropped the cache; "Disk usage" measures `/root/.gradle`.
- **F32.** A manual release whose tag exists attached the new build to the old tag. A manual run now fails first (§5.8); retry a failed tag release by re-running its own run.
- **F33.** `stamp_version.sh` and the release's tag check matched line by line, so `$'v1.2.3\n'` passed. They match the whole string.
- **F34.** CI kept about 6.6 GB of caches, mostly a Gradle cache per PR, and 2.3 GB of artifacts. Now: no caches, builds only from a manual run with `upload-builds`, every upload kept 1 day, enforced by `check_actions_storage.sh` (§5.12).

## 5. Design

### 5.1 `project.godot`

`config/version="0.0.0"`, set by `stamp_version.sh` and shown by the HUD (F6). `steer_left`, `steer_right` and `pause` bind physical keys (Left/A, Right/D, Esc/P), and `ui_accept` keeps its built-in events (F14). `import_etc2_astc=true` (F30).

### 5.2 Repository hygiene

Commit `*.uid`, `*.import`, `addons/gut/` and `build/.gdignore`; ignore `.godot/`, `/android/` and the rest of `/build/`; never commit keystores. `.gitattributes`: `* text=auto eol=lf` (F18, F25).

### 5.3 `.gdlintrc` and `.gutconfig.json`

`.gdlintrc` skips `.git`, `.godot`, `addons`, `android` and `build`, sets `max-public-methods: 40` (F15), and keeps gdtoolkit's other defaults: `max-line-length: 100`, `max-file-lines: 1000`, `function-arguments-number: 10`, `max-returns: 6` and `class-definitions-order`. `.gutconfig.json` runs `res://tests/` with subfolders (F9), then `post_run_script` (F29). M5 added `pre_run_script` (docs/M5.md L1).

### 5.4 `export_presets.cfg`

`Web`, `Android APK` and `Android AAB`, each with `exclude_filter="addons/gut/*, tests/*, tools/*"` (F13), and no keystore settings: `release.yml` passes them in env vars (F7).

### 5.5 `tools/ci/` scripts

Each sources `_common.sh`: `set -euo pipefail`, the repository root, `$GODOT` (default `godot`), logs in `build/reports/`, `run_godot <seconds> <log> <args>` with a time limit (F5), and `fail_on`, which skips `IGNORE_RE` (the image's missing-fontconfig line). `import.sh`, `check_scripts.sh`, `smoke.sh` and `export.sh` fail on any line that matches `ANY_ERROR_RE`, `^(SCRIPT |USER )?ERROR:|Parse Error|Failed to load script` (F10). `check_scripts.sh` also needs its `loaded N scripts` line (F2), and `export.sh` checks its outputs (F26). `run_tests.sh` fails on a parse error, "have not been imported", `[GUT ERROR]`, GUT's exit code, or a JUnit file that is missing or counts 0 tests (F1, F3, F9, F29). `lint.sh` runs gdlint, gdformat, the determinism rule, shellcheck, `check_versions.sh` (F24) and `check_actions_storage.sh` (§5.12).

**Determinism rule** (IP §5.3, F4). In `autoload road world car disasters areas setpieces`, it flags the global `randf`, `randi`, `randfn`, `randf_range`, `randi_range`, `randomize`, `seed` and `rand_from_seed`, and any `.shuffle(` or `.pick_random(`. Calls on a `RandomNumberGenerator`, strings, comments and a `func` declaration's name pass. So don't name a method `seed` or `randf`, and shuffle with a Fisher-Yates helper on the stream's generator.

### 5.6 `.github/actions/godot-env/action.yml`

It moves the image's export templates and editor settings to the job's `$HOME` and imports the project, with no cache (F34). With `android: true` it installs the SDK packages and NDK 29 (F11).

### 5.7 `.github/workflows/ci.yml`

`lint` and `test`, then `export-web` and `export-android` (APK and AAB); all but `lint` run in `barichello/godot-ci:4.7.2`. On `main`, `deploy-web` follows every export (Q7). Inline steps run bash with `pipefail`, and each job has `timeout-minutes` (F5). "Disk usage" follows each Android export (§8). Uploads follow §5.12. Since M5, `test` fails if the checks change the tree (docs/M5.md L28).

### 5.8 `.github/workflows/release.yml`

For `v*.*.*` tags, or by hand with the tag as input, which makes a draft (F19). `test` validates the tag (F33), fails a manual run whose tag exists (F32), and runs the checks. `android-release` stops at "Check signing secrets" without them, and decodes the keystore under `$RUNNER_TEMP` (F7). `publish` creates the release and deletes the build artifacts (F34).

### 5.9 `.github/workflows/copilot-setup-steps.yml`

The job must be named `copilot-setup-steps` and use only the keys the agent honours (`timeout-minutes` at most 59), so `GODOT_VERSION` is a step env var. It installs Python 3.12 with gdtoolkit, and Godot 4.7.2 from `godotengine/godot-builds` as `/usr/local/bin/godot`, checked against `SHA512-SUMS.txt`, then imports the project. It installs no export templates or Android SDK, so exports are checked only in CI. The agent uses the copy on `main`.

### 5.10 Version bump procedure

In one PR (changing IP §7.1): the godot-ci tag in every workflow, `GODOT_VERSION`, `config/features`, the SDK and NDK in `godot-env` (from the release's `platform/android/java/app/config.gradle`), and GUT and gdtoolkit if needed. `check_versions.sh` checks that the first three agree, and that the image tag is a complete `x.y.z`.

### 5.11 `.github/dependabot.yml`

GitHub Actions, weekly.

### 5.12 Actions storage

The least storage, even if CI is slower (Q9, F34):

1. **No caches:** no cache action or cache input (`cache: pip`), no `type=gha`, and actions that cache by default turned off with a written-out value (`cache-disabled: true`; for setup-python, leave `cache` out: `cache: false` is an error).
2. **Artifacts only where needed:** PR and `main` runs upload no builds; a manual CI run with `upload-builds` does (it needs `ci.yml` on `main`). `deploy-web` deletes the Pages artifact, and `publish` the release's builds, once used; to deploy a commit again, re-run all its jobs. Reports and logs stay in the job log.
3. **Every upload sets `retention-days: 1`.**

`tools/ci/check_actions_storage.sh`, run by `lint.sh`, enforces rules 1 and 3 in every YAML file under `.github/`. It reads inputs only from the keys right under `with:`, in any case, searches all other text (`run:` scripts too) for `type=gha`, and fails on YAML it can't read plainly, such as flow-style `uses:` or `with:`. The cost: each AAB export downloads Gradle's dependencies, 75 s against 34–37 s with a warm cache.

## 8. Risks

- **Runner disk.** The image, the SDK and NDK 29, and Gradle share the runner's disk, and an AAB job could run out. "Disk usage" prints `df -h` and the SDK's and Gradle's sizes after each Android export, even a failed one. If space runs low, remove unused SDK packages or preinstalled runner tools.
- **Image pulls** (F20). If one takes over 2 min, run `test` with Godot downloaded directly; against rate limits, use `container.credentials` or a GHCR mirror.
- **Downloads.** Without caches, each AAB job downloads NDK 29 and Gradle's dependencies, so a flaky network can fail it: re-run it. If that keeps happening, build the AAB only on `main` and for releases (Q1's alternative).
- **gdformat** can mis-indent the line after a multi-line lambda (Scony/godot-gdscript-toolkit#424): prefer named functions.
